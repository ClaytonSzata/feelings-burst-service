# High-level Overview

The Feelings Burst helps identify emotions with a high degree of granularity and is is based on a modified version of the Feelings Wheel created by Gloria Wilcox. 

## Sequence of Requests

The Client will make a call to the service in order to begin selecting the high-level emotion. The service then provides a list of high-level emotions. The client will then select one.After selecting an emotion, the service will return a new set of selections
